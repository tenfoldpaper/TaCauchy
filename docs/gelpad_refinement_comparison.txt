推荐使用场景

┌─────────────────────┬──────────────────────────────────┐
│   场景              │   推荐配置                       │
├─────────────────────┼──────────────────────────────────┤
│ 快速原型开发        │ fast_prototype 或 standard       │
│ 实时仿真            │ realtime                         │
│ 离线训练            │ balanced 或 offline_training     │
│ 小接触面积          │ small_contact                    │
│ 大接触面积          │ large_contact                    │
│ 滚动接触            │ rolling_contact                  │
│ 多点接触/抓取       │ multi_point_contact              │
│ 高精度研究          │ high_precision                   │
│ 验证和测试          │ validation 或 ultra_precision    │
└─────────────────────┴──────────────────────────────────┘

使用建议

1. 开始阶段
   - 使用 "balanced" 配置进行初步测试
   - 观察中心区域的变形是否足够精确
   - 检查仿真性能是否可接受

2. 调优阶段
   - 如果精度不够，尝试 "high_precision"
   - 如果性能不够，尝试 "fast_prototype"
   - 根据实际接触区域调整 center_region_ratio

3. 生产阶段
   - 为不同场景创建自定义配置
   - 记录最佳实践和参数设置
   - 定期验证仿真精度
