参数控件说明
================================================================================

1. FloatDrag 控件 (浮点数拖拽)
   ┌──────────────┐
   │  0.500  ▲▼  │  ← 可以点击上下箭头调整
   └──────────────┘  ← 也可以直接拖拽数字

2. IntDrag 控件 (整数拖拽)
   ┌──────────────┐
   │   10    ▲▼  │  ← 整数值调整
   └──────────────┘

3. CheckBox 控件 (复选框)
   [☐] 未选中
   [☑] 已选中

4. Button 控件 (按钮)
   ┌──────────────┐
   │   Standard   │  ← 点击应用预设
   └──────────────┘

使用流程图
================================================================================

开始
  │
  ├─→ 选择Mesh对象
  │
  ├─→ 选择配置方式
  │    │
  │    ├─→ 方式1: 点击预设按钮
  │    │    │
  │    │    ├─→ Standard  (标准，无加密)
  │    │    ├─→ Fast      (快速原型)
  │    │    ├─→ Balanced  (平衡，推荐)
  │    │    └─→ High      (高精度)
  │    │
  │    └─→ 方式2: 手动调整参数
  │         │
  │         ├─→ 调整基础参数
  │         │    ├─ Edge Length Ratio
  │         │    ├─ Epsilon Ratio
  │         │    ├─ Stop Quality
  │         │    └─ Max Iterations
  │         │
  │         └─→ 调整中心加密参数
  │              ├─ Enable Center Refinement
  │              ├─ Center Region Ratio
  │              ├─ Center Edge Length
  │              └─ Transition Ratio
  │
  ├─→ 点击 "Compute Tet Mesh"
  │
  ├─→ 等待生成完成
  │
  ├─→ 查看结果
  │    ├─ 顶点数量
  │    ├─ 四面体数量
  │    ├─ 表面三角形数量
  │    └─ 配置信息
  │
  └─→ 完成

快捷操作
================================================================================

1. 快速应用平衡配置:
   点击 [Balanced] → 点击 [Compute Tet Mesh]

2. 快速切换预设:
   [Standard] → [Fast] → [Balanced] → [High]
   (参数会立即更新，但不会自动生成)

3. 微调参数:
   点击预设 → 手动调整个别参数 → 生成

4. 批量处理:
   配置参数 → 选择对象1 → 生成 → 选择对象2 → 生成
   (参数会保持，不需要重新配置)

注意事项
================================================================================

⚠️  必须选择Mesh类型的prim，不能是Xform
⚠️  生成过程中请勿操作场景
⚠️  大型网格可能需要较长时间
⚠️  启用中心加密会增加生成时间
⚠️  参数调整后需要重新点击生成按钮

✓  可以随时调整参数
✓  预设配置已经过优化
✓  生成的数据会自动保存到USD
✓  可以在Raw USD Properties中查看数据
