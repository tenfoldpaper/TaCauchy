[U] = UIPC Object
      - Can physically interact with gelpad
      - Has tetrahedral mesh for FEM simulation
      - Configured with UipcObjectCfg
      - Kinematic mode (fixed in space)
      - Total: 5 objects

[P] = PhysX Rigid Body
      - Visual reference only
      - No UIPC interaction with gelpad
      - Configured with RigidObjectCfg
      - Kinematic mode (fixed in space)
      - Total: 4 objects

═══════════════════════════════════════════════════════════════════════════════
                              NOTES
═══════════════════════════════════════════════════════════════════════════════

• All objects at same height: z = 0.03m (3cm above ground)
• All objects at same X position: x = 0.5m
• Spacing: 2.5cm (0.025m) between adjacent objects
• Center reference: cylinder at (0.5, 0.0, 0.03)

• UIPC objects require precomputed tetrahedral mesh in USD file
• PhysX objects lack tet mesh data, used for visual variety only
• Robot can interact with all UIPC objects via gelpad contact
• PhysX objects will not respond to gelpad contact

• Configuration file: scripts/demos/shape_touch/simple_tactile_env.py
• Main script: scripts/demos/shape_touch/simple_tactile_demo.py


═══════════════════════════════════════════════════════════════════════════════
                            USAGE EXAMPLE
═══════════════════════════════════════════════════════════════════════════════

python scripts/demos/shape_touch/simple_tactile_demo.py --sensor gelsight

Then drag the red goal cube in Isaac Sim to move the robot and touch objects.
UIPC objects will deform the gelpad and generate tactile images.
PhysX objects are visible but won't interact with the sensor.
